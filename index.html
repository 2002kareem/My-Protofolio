Airline

This project performs an exploratory data analysis (EDA) on airline flight data to understand the factors influencing ticket prices and flight frequencies. Using Python libraries like Pandas, Matplotlib, and Seaborn, the analysis examines various dimensions such as airline performance, departure and arrival times, source and destination cities, and flight classes (Economy vs. Business). Key insights include identifying the most expensive and longest flights, calculating mean prices across different airlines and routes, and visualizing how booking lead time ("days_left") impacts the final ticket cost.
Results: This project concludes that airline ticket prices are primarily driven by the travel class and the number of days left before departure, with Business class and last-minute bookings significantly increasing costs.

Tools Used: Python, Pandas , numpy , matplotlib , seaborn
